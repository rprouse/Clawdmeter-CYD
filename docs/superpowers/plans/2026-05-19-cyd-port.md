# CYD Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port Clawdmeter firmware and daemon from the Waveshare ESP32-S3 AMOLED board to the AOKIN ESP32-2432S028R CYD, replacing the display/touch/sensor stack and dropping BLE HID, battery, and IMU features.

**Architecture:** Replace hardware abstraction layer (display + touch + sensors), keep UI/BLE-data architecture intact. New stack: TFT_eSPI (ILI9341 240×320) + XPT2046 resistive touch + classic ESP32 + LVGL 9 partial-render with SRAM buffers (no PSRAM). Daemon updates in place with new BLE name and UUIDs.

**Tech Stack:** PlatformIO (stock `espressif32@6.x`), Arduino framework, LVGL 9.1, TFT_eSPI 2.5, NimBLE-Arduino 1.4, Bash daemon on Linux host.

**Source of truth:** `docs/superpowers/specs/2026-05-19-cyd-port-design.md`. When the plan and spec disagree, the spec wins.

**Verification model:** Embedded firmware has no unit-test runner. Each task that touches the firmware is verified by `pio run` (compile), `pio run -t upload` (flash), and either `screenshot.sh` (UI) or `pio device monitor` (serial log) as appropriate. Daemon changes are verified by running the script against the device.

### Task 2.1: Skeleton `main.cpp` with TFT_eSPI + LVGL

**Files:**

This task replaces the contents of `main.cpp` with a minimal working LVGL skeleton. Subsequent tasks add touch, BLE, UI, etc.

- [ ] **Step 1: Replace `main.cpp` with the skeleton**

```cpp
#include <Arduino.h>
#include <TFT_eSPI.h>
#include <lvgl.h>
#include "display_cfg.h"

static TFT_eSPI tft;

// Double-buffered partial render. Two 320×40 buffers in SRAM (~25 KB each).
#define BUF_LINES 40
static uint16_t buf1[SCR_W * BUF_LINES];
static uint16_t buf2[SCR_W * BUF_LINES];
static lv_display_t* lv_disp = nullptr;

static void disp_flush(lv_display_t* disp, const lv_area_t* area, uint8_t* px_map) {
    uint32_t w = area->x2 - area->x1 + 1;
    uint32_t h = area->y2 - area->y1 + 1;
    tft.startWrite();
    tft.setAddrWindow(area->x1, area->y1, w, h);
    tft.pushPixelsDMA((uint16_t*)px_map, w * h);
    tft.endWrite();
    lv_display_flush_ready(disp);
}

static uint32_t millis_cb(void) { return millis(); }

void setup() {
    Serial.begin(115200);
    delay(200);
    Serial.println("Clawdmeter / CYD boot");

    tft.begin();
    tft.setRotation(TFT_ROTATION);
    tft.fillScreen(TFT_BLACK);
    tft.initDMA();

    lv_init();
    lv_tick_set_cb(millis_cb);
    lv_disp = lv_display_create(SCR_W, SCR_H);
    lv_display_set_flush_cb(lv_disp, disp_flush);
    lv_display_set_buffers(lv_disp, buf1, buf2, sizeof(buf1),
                           LV_DISPLAY_RENDER_MODE_PARTIAL);

    // Smoke test: orange rectangle on black
    lv_obj_t* scr = lv_screen_active();
    lv_obj_set_style_bg_color(scr, lv_color_hex(0x000000), 0);
    lv_obj_set_style_bg_opa(scr, LV_OPA_COVER, 0);
    lv_obj_t* box = lv_obj_create(scr);
    lv_obj_set_size(box, 200, 80);
    lv_obj_center(box);
    lv_obj_set_style_bg_color(box, lv_color_hex(0xd97757), 0);
    lv_obj_t* lbl = lv_label_create(box);
    lv_label_set_text(lbl, "CYD bring-up");
    lv_obj_center(lbl);
}

void loop() {
    lv_timer_handler();
    delay(5);
}
```

**Files:**

The current `touch.{h,cpp}` use CST92xx; delete its contents and use TFT_eSPI's built-in XPT2046 helper (`tft.getTouch()`), or for finer control use the SPI directly. For the first pass, `tft.getTouch()` is sufficient.

- [ ] **Step 1: Replace `touch.h`**

// Public state — written by touch_read() once per main-loop iteration.
extern volatile bool touch_pressed;
extern volatile uint16_t touch_x;  // screen pixels, post-calibration
extern volatile uint16_t touch_y;

// Initialize touch (load calibration from NVS, run cal screen if missing).
void touch_init(void);

- [ ] **Step 2: Replace `touch.cpp`**

```cpp
#include "touch.h"
#include <Arduino.h>
#include <Preferences.h>
#include <TFT_eSPI.h>

extern TFT_eSPI tft;  // owned by main.cpp

volatile bool     touch_pressed = false;
volatile uint16_t touch_x = 0;
volatile uint16_t touch_y = 0;

static uint16_t cal_data[5] = {0,0,0,0,0};  // TFT_eSPI calibration format
static bool cal_loaded = false;

static const char* NVS_NS  = "clawd";
static const char* NVS_KEY = "tcal_v1";  // single blob: 5 uint16 (10 bytes)

static bool load_cal_from_nvs(void) {
    Preferences p;
    if (!p.begin(NVS_NS, true)) return false;
    size_t n = p.getBytesLength(NVS_KEY);
    if (n != sizeof(cal_data)) { p.end(); return false; }
    p.getBytes(NVS_KEY, cal_data, sizeof(cal_data));
    p.end();
    return true;
}

static void save_cal_to_nvs(void) {
    Preferences p;
    p.begin(NVS_NS, false);
    p.putBytes(NVS_KEY, cal_data, sizeof(cal_data));
    p.end();
}

static void run_calibration_screen(void) {
    tft.fillScreen(TFT_BLACK);
    tft.setTextColor(TFT_WHITE, TFT_BLACK);
    tft.setTextDatum(MC_DATUM);
    tft.drawString("Touch each corner", 160, 100, 2);
    tft.drawString("(top-left first)", 160, 120, 2);
    tft.calibrateTouch(cal_data, TFT_WHITE, TFT_BLACK, 15);
    save_cal_to_nvs();
    cal_loaded = true;
}

void touch_init(void) {
    if (load_cal_from_nvs()) {
        tft.setTouch(cal_data);
        cal_loaded = true;
        return;
    }
    run_calibration_screen();
    tft.setTouch(cal_data);
}

void touch_read(void) {
    if (!cal_loaded) return;
    uint16_t x, y;
    if (tft.getTouch(&x, &y)) {
        touch_pressed = true;
        touch_x = x;
        touch_y = y;
    } else {
        touch_pressed = false;
    }
}

void touch_force_recalibrate(void) {
    Preferences p;
    p.begin(NVS_NS, false);
    p.remove(NVS_KEY);
    p.end();
    ESP.restart();
}
```

## Notes for the implementing engineer

- **Embedded "tests" are flash + observe.** When a step says "Expected: X", it means flash the firmware and check that X is what you see on the device or in the serial log. There is no `pytest`.
- **The screenshot workflow is your friend.** The CLAUDE.md says to use it on every UI iteration. Read the PNG with the Read tool and verify visually before committing. Adjust the temporary `ui_show_screen()` line in `setup()` to start on whatever screen you are iterating on; revert before the final commit.
- **If something does not compile**, read the error carefully — most failures will be a font/icon symbol you forgot to rename or a missing `LV_FONT_DECLARE`. Do not paper over with conditional compilation.
- **Touch is resistive.** Press deliberately. If taps land off-target, run `touch-cal` (serial command) and recalibrate.
- **Do not skip the `huge_app.csv` partition.** LVGL + NimBLE + the fonts together push past the 1.5 MB default app slot. If the linker complains about "image size", confirm the partition setting.
